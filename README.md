## 怎么用

- 开工前按 SOP 第 2 节确定原型与开关，签《首发范围单》。
- 按阶段执行，逐项核对交付物与「不得进入下一阶段」条件。
- 打印与转发使用 `安卓上架SOP.pdf`。
