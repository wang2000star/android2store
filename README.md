# 咕咕嘎嘎(gugugaga) 安卓上架 SOP

中国大陆安卓渠道的上架执行流程，覆盖九个阶段：范围 → 主体 → 备案许可 → 资金 → 产品后台 → 测试备料 → 内测 → 提审发布 → 上线后。

| [安卓上架SOP.md](安卓上架SOP.md) | 同一内容的源文件，便于检索与修改 |

阶段 7 与阶段 8 之间设门禁「内测关闭、提审包冻结」，通过后方可向商店提交。开工前按第 2 节确定原型与开关，签署《首发范围单》。
