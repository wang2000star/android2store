## 核验原则

工具清单**不采信第三方镜像站、聚合站或博客转述**，只记录从项目源头实际读到的内容：

- GitHub 仓库的 `README`、源码、`SKILL.md`
- 官方文档：Android Developers、Google Developers Blog、Firebase、Supabase

凡未能从源头读到的功能，不写入清单。

## 使用方式

- 克隆：`git clone https://github.com/wang2000star/android2store.git`（也可使用 SSH 地址）。
- Markdown 文件可直接用任意 Markdown 阅读器或 GitHub 网页打开。
- SVG 流程图可用浏览器直接打开。
- 工具清单中的命令需在对应开发环境中执行；涉及生产数据库、支付或上架的操作请先人工复核。

> 本项目涉及中国大陆合规事项，行政许可适用性、数据合规与各商店当前字段要求，应以主管机关和渠道后台的最新口径为准。
