# 咕咕嘎嘎(gugugaga) 安卓上架 SOP

中国大陆安卓渠道的上架执行流程。**只有一份文档需要读**，其余是查依据时用的参考资料。

## 从这里开始

➡️ **[安卓上架SOP.md](安卓上架SOP.md)** —— 九个阶段，每个阶段写清：做什么、谁做、交出什么、什么算做完。

要直接发给同事或打印：**[安卓上架SOP.pdf](安卓上架SOP.pdf)**（A4，10 页，与 md 内容一致）。

配套一页图：[上架流程总览.svg](上架流程总览.svg)（九个阶段 + 那道门禁）。

## 怎么用

- 开工前先把 SOP 第 2 节的原型和开关定完，签《首发范围单》；范围不定，后面全返工。
- 逐阶段打勾，做到「不放行」那条就不许往下走。
- 打印或转发直接用 `安卓上架SOP.pdf`，不用再排版。
